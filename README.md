## Sobre o projeto

O **CNPJ Finder** é uma ferramenta desenvolvida para **automatizar a busca de CNPJs a partir do nome de empresas**.

## Como funciona

A aplicação recebe uma lista de nomes de empresas, uma por linha, e realiza uma busca automatizada pelo CNPJ de cada uma. Para cada empresa, o resultado exibe o CNPJ já formatado e o link da fonte onde ele foi encontrado.

## Funcionalidades

- Busca automatizada de CNPJ a partir do nome da empresa
- Processamento de múltiplas empresas de uma só vez
- Formatação do CNPJ no padrão `XX.XXX.XXX/XXXX-XX`
- Exibição do link da fonte de cada resultado
- Rodízio automático de chaves quando o limite de uma delas é atingido
- Identificação de empresas sem resultado ou com erro na busca
