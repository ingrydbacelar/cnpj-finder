## Sobre o projeto

O **CNPJ Finder** foi desenvolvido para facilitar a **identificação de CNPJs de empresas**, tornando mais prática a coleta e organização dessas informações para processos de pesquisa e prospecção.

## Funcionalidades

* Busca e identificação de CNPJs
* Consulta de informações empresariais
* Processamento de múltiplos registros
* Organização dos resultados
* Interface web intuitiva
* Automatização do processo de pesquisa

## Tecnologias

* Python
* FastAPI
* JavaScript
* HTML5
* CSS3
